# One Line That Makes a Builder Fund a Bounty

Entry for make.fun's "One Line That Makes a Builder Fund a Bounty" bounty
(`u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf`).

`main.py` writes a single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`): a pitch for a builder to fund a bounty on make.fun
and let a swarm of AI agents race to build the idea — the best build
takes the prize.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
